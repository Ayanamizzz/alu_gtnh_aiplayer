想看一个地方、一张草稿或服务器上的一张图纸长什么样，或者要看主人传的图片时看：有哪几种图、怎么要、图能信到什么程度。

# 有哪些图
这三样只有你的模型能看图时才在工具清单里（看不了图时怎么办见最后一节）：
- view_area：看实际世界。`view:"eyes"` 从当前眼位看眼前；默认仍把一个盒子画成示意图，给两个对角（每边最多 64 格），不给就是看自己周围。
- view_draft 加 picture：把图纸草稿画成图；再加 blueprint: true，画的是服务器上的那张图纸（list_designs 列的 blueprints）。一张图每边最多 256 格，更宽的图纸用 x1…z2 挑一块（从图纸最低的角 0 数起）。
- view_image：看主人在面板上传的图片。

# 从自己的眼睛看现场

直接调用 `view_area {view:"eyes", radius:12}`。身体在这次请求里一起记录真实眼位、朝向和周围方块，大脑把冻结快照画成512×288的低清JPEG。它是现场数据的第一人称重建，不是设计图纸，也不是Minecraft客户端截图。主人不在线、没有打开面板也能用。

- 用于建筑视觉复查：进屋看树叶是否侵入、窗户或通道是否被意外挡住，再结合图纸/要求判断是否需要修改。数量、方块身份和精确坐标仍问查询工具。
- 它不会移动或转头，也不剖开墙壁。要看别处，先通过正常动作改变实际站位/朝向再请求。不能同时给corners（x1…z2）、from或layer。
- radius默认12，范围0–31；以眼睛所在格为中心。31对应每边63格，受world.blocks每边64格的协议限制。半径越大采集越多，通常先用默认值；盒外的中性背景不是已确认的空地。
- 画面带采集时间、tick、维度、眼位和朝向。渲染过程中世界可能继续变化，图代表采集时刻，不是持续直播。
- 品红色是未知区块或缺贴图的替代，不是现场原有的颜色。缺失与近似清单在结果及data.diagnostics里。
- 管线/机器可能被画成整块，门、楼梯、玻璃板等形状和开合可能不准；简化形状也会额外遮挡。不要根据这些替代形状判断精确间隙、机器型号或接线。实体、动态机器细节、动画和真实光照尚不渲染。
- 第一次使用需要启动本地渲染器，可能等待十几到二十多秒；后续复用。缺Chrome/Chromium或贴图、忙、取消、超时都会明确报错，不会偷偷改成示意图。默认总时限45秒，部署者可通过AIPLAYER_VIEW_TIMEOUT_MS调整。
- 要让图片进入模型消息，直接调用view_area。run_program中的tool()适合读取文字/data，不把其中图片当作模型已经看见。

# 示意图的四种看法
view_area 的其他 view、view_draft 的 picture 可选：
- iso：站在一个角的斜上方往下看，每个方块看得见顶面和两个侧面。看整体形状用它。from 是站在哪个角：southeast（默认）、southwest、northwest、northeast。站在东南角时，图上左边的面朝南、右边的面朝东；想看背面就换成对角。
- top：从正上方看，像地图：上北下南、左西右东，高的地方亮一些。图的上边标着 x 坐标，左边标着 z 坐标。
- side：从一边平着看（立面）。from 是站在哪一边：south（默认，朝北看）、west、north、east。远处的颜色暗一些。图上标着横向的坐标和 y。
- layer：只看某一层（layer 给 y），从上往下看。检查墙的走向、每一层的布局用它。
- 示意图想看建筑里面：把范围的上界（y2）压到屋顶以下，或者用 layer。这是剖视，和eyes模式的真实眼位遮挡不同。

# 方块颜色示意图能信什么
- 它是按方块颜色画的示意图，不是游戏里的画面：没有贴图，没有光影；楼梯、栅栏、火把、花草这类不是整块的方块只是画得小一点；动物、掉落物这些实体不画。
- 图上有图例：哪个色块是哪种方块、有多少个。名字后面带 ? 的，颜色是为了区分随便配的，不是它真实的颜色；带 ~ 的是按名字猜的。
- 品红色的记号是你自己，青色的是别的玩家。深灰近黑的一块是没加载的区块，那里有什么不知道。
- 用图来判断：形状对不对、布局合不合理、好不好看、东西大概在哪。
- 数量、方块 id、精确的坐标不要从图上读：以 scan_area、find_blocks、inspect_block 和材料表为准。

# 省着用
- 一张图的开销顶得上几千字。要看形状、布局、样子的时候才要图；查询工具能直接回答的事不要用图。
- 图只在这一轮里留着：到了后面的轮，它就变成一句“之前看过的图”，要再看得重新要一张。所以看完就把结论（哪里不对、打算怎么改）用文字说出来或记下来。
- 一轮里同时最多留着 4 张图，再要新的，最早的那张就不在了。

# 你的模型看不了图时
- view_draft 还在工具清单里，只是没有 picture、from、layer 这三个参数：它给尺寸、材料表和一片片的字符画（加 blueprint: true 是服务器上的图纸）。
- view_area 和 view_image 不在工具清单里，成了库函数（run_program 的说明后面那份索引里有），给的是文字：`return (await tool("view_area", { radius: 8 })).text` 是范围、里面各种方块各多少、一层一层各有什么；`(await tool("view_image", { name })).text` 是图片的尺寸、透明的占多少、主要颜色。要每一格是什么方块，用库函数 read_blocks。
- eyes模式的图片也只会交给支持视觉的模型；不支持时，文字只说明取景和限制，不代表模型看到了场景。图片仍留给面板查看。
- 这时候判断形状主要靠 view_draft 的字符预览和 scan_area；好不好看，请主人到控制面板的“图纸”页看。
